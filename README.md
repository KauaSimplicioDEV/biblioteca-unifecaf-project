# Biblioteca Digital UniFECAF

Primeira interface web da biblioteca digital da UniFECAF, feita só com HTML e CSS (projeto da disciplina Design Web).

## Estrutura
```
biblioteca-unifecaf/
├── index.html
├── css/style.css
└── assets/imagens/   (ilustrações em SVG)
```

## Como abrir
Abra o `index.html` no navegador. Não há dependências nem etapa de build. As fontes (Poppins e Lora) vêm do Google Fonts e há fontes alternativas caso não carreguem.

## Publicar no GitHub Pages
1. Crie um repositório público e envie estes arquivos na raiz.
2. Em **Settings → Pages**, escolha *Deploy from a branch*, branch `main`, pasta `/ (root)`.
3. O site ficará em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.
